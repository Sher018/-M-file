# Верификация и тестирование комплекса SC_Calculator

Версия документа соответствует `sc_version.m`.

## 1. Цели

- **Модульная проверка** функций расчёта ударного тока, постоянной времени τ, симметричных составляющих и токов КЗ на эталонных формулах и допусках.
- **Сквозная проверка** экспорта результатов во временный каталог.
- **Интеграционный тест** чтения `network_parameters.xlsx` при наличии файла и пакета `io` (GNU Octave).

## 2. Состав набора

Файл `tests/verify_sc_suite.m` последовательно выполняет сценарии (имена выводятся в консоль):

| № | Сценарий |
|---|----------|
| 1–6 | `func_impact_current`: по умолчанию, скаляр, R=0, X≈0, средний R/X, большой R/X |
| 7–9 | `func_network_tau`: согласование с Z·Zбаз, ограничение τ сверху и снизу |
| 10 | `func_sym_components` vs явные формулы E/Z |
| 11 | `func_sc_currents` vs I1, I2, I0 и коэффициент кА |
| 12 | `func_pack_results_meta`: наличие полей и численные значения |
| 13 | `func_export_results` в временный каталог |
| 14 | Импорт Excel + полный расчёт токов (SKIP, если нет файла или `io`) |

Пропуски помечаются **SKIP** (не считаются ошибкой), в том числе если в корне проекта нет `network_parameters.xlsx`.

## 3. Запуск

Из каталога проекта в **MATLAB** или **GNU Octave**:

```matlab
run_sc_tests
```

Либо явно:

```matlab
addpath('tests')
verify_sc_suite          % то же: verbose=true, stopOnError=false, writeReport=true
[nPass, nFail, nSkip] = verify_sc_suite(false, false, false);  % без консоли и без файла
verify_sc_suite(true, true, true);   % останов на первом FAIL
```

В Octave перед интеграционным тестом должен быть доступен пакет **io**:

```octave
pkg load io
run_sc_tests
```

## 4. Артефакты

После успешного или частичного прогона создаётся (при `writeReport=true`):

- `results/docs/verification_report.txt` — список PASS/FAIL/SKIP и итоговая строка.

## 5. Критерии приёмки

- **FAIL = 0** — комплекс считается прошедшим верификацию на данной машине.
- **SKIP > 0** допустим (нет Excel-фикстуры или `io`); для полной приёмки рекомендуется положить учебный `network_parameters.xlsx` в корень проекта.

## 6. Вспомогательные функции

- `tests/sc_assert_close.m` — сравнение вещественных скаляров.
- `tests/sc_assert_close_c.m` — сравнение комплексных скаляров по модулю разности.
