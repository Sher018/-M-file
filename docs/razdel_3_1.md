# 3.1 Структура и организация комплекса M-file сценариев

Разработанный программный комплекс SC_Calculator предназначен для автоматизированного расчёта токов короткого замыкания (КЗ) в электрических сетях напряжением до 110 кВ по упрощённой схеме замещения с использованием метода симметричных составляющих Фортескью. Комплекс реализован в виде набора взаимосвязанных M-file сценариев на языке MATLAB/Octave и обеспечивает кроссплатформенное выполнение расчёта как в среде MATLAB, так и в GNU Octave.

Архитектура комплекса построена по модульному принципу: каждый вычислительный этап вынесен в отдельную функцию с чётко определённым входом и выходом. Такой подход соответствует методологии поэтапной разработки прикладного программного обеспечения в электроэнергетике, облегчает верификацию отдельных блоков и позволяет использовать модули независимо друг от друга при доработке математической модели.

## 3.1.1 Общая структурная схема комплекса

На рисунке 3.1 представлена структурная схема программного комплекса M-file сценариев. В верхней части схемы показаны альтернативные точки входа: графический интерфейс `sc_calculator_gui.m` (только MATLAB), сценарии GNU Octave (`run_sc_octave.m`, `oct_sc_menu.m`) и унифицированная функция `run_all.m`, объединяющая режимы расчёта и верификации. Все перечисленные точки входа инициируют выполнение главного сценария `main_calc_sc.m`, который координирует последовательный вызов вычислительных модулей и модулей вывода результатов.

## 3.1.2 Назначение основных модулей

**Главный сценарий `main_calc_sc.m`** — центральный модуль комплекса. Он выполняет инициализацию рабочей среды (добавление путей, создание каталогов результатов, загрузка пакета `io` в Octave), последовательный вызов всех расчётных функций, вывод сводки в командное окно и запуск экспорта. Имя входного Excel-файла может быть задано аргументом вызова, что повышает гибкость сценария при пакетных расчётах.

**Модуль `func_import_data.m`** обеспечивает импорт параметров элементов сети из таблицы Excel. Функция считывает столбцы `R1`, `X1`, `R0`, `X0`, `U_nom`, при наличии — `R2`, `X2`, переводит сопротивления в относительные единицы при базисной мощности Sбаз = 100 МВА и формирует комплексные сопротивления прямой, обратной и нулевой последовательностей Z1, Z2, Z0. ЭДС системы принимается постоянной E = 1,05 о.е. На выходе также возвращается служебная структура `scInfo` с базисным сопротивлением и признаком задания Z2 из Excel.

**Модуль `func_sym_components.m`** реализует расчёт симметричных составляющих токов по методу Фортескью: I1 = E/Z1, I2 = E/(Z1+Z2), I0 = E/(Z1+Z2+Z0). Результаты используются на следующем этапе для определения токов различных видов КЗ.

**Модуль `func_sc_currents.m`** переводит составляющие токов в действующие значения токов трёхфазного (Ik3), двухфазного (Ik2) и однофазного (Ik1) короткого замыкания в килоамперах с учётом номинального напряжения Uном.

**Модуль `func_impact_current.m`** вычисляет ударный ток iуд = kуд·Ik3·√2. Коэффициент kуд определяется по суммарному отношению активного и реактивного сопротивлений цепи прямой последовательности (аппроксимация по рекомендациям IEC 60909-0) либо задаётся явно.

**Модуль `func_network_tau.m`** рассчитывает постоянную времени апериодической составляющей τ ≈ X/(ωR) по суммарному сопротивлению Z1 в омах. Полученное значение используется при построении осциллограммы переходного процесса.

**Модуль `func_pack_results_meta.m`** объединяет промежуточные параметры расчёта (версия ПО, имя входного файла, модули сопротивлений, kуд, τ, частота) в единую структуру для последующей записи в отчёт и таблицу результатов.

**Модуль `func_oscillogram.m`** строит осциллограмму мгновенного тока при КЗ по упрощённой RL-модели с учётом угла коммутации ψ и опциональным отображением трёх фаз. График сохраняется в каталог `results/figures/` в формате PNG высокого разрешения (300 dpi).

**Модуль `func_export_results.m`** записывает итоговую таблицу расчёта в файл Excel (MATLAB) или TSV (GNU Octave). **Модуль `func_report.m`** формирует текстовый отчёт в кодировке UTF-8 с перечислением всех основных результатов и параметров модели.

**Графический интерфейс `sc_calculator_gui.m`** реализован на базе `uifigure` и предназначен для инженерного применения комплекса без редактирования M-file. Интерфейс дублирует логику `main_calc_sc.m`, дополняя её возможностью интерактивного выбора файла параметров и настройки параметров осциллограммы.

## 3.1.3 Организация файлов и каталогов

Исходные M-file размещаются в корневой папке проекта `SC_Calculator_MATLAB`. Каталог `docs/` содержит инструкцию пользователя и материалы верификации. Каталог `tests/` — модульные и интеграционные тесты. Результаты расчёта автоматически сохраняются в `results/figures/`, `results/` и `results/docs/`; при первом запуске эти каталоги создаются функцией `sc_ensure_results_dirs.m`.

Такая организация обеспечивает воспроизводимость расчётов, удобство сопровождения комплекса и соответствие требованиям оформления программной документации магистерской диссертации.
