# Инструкция по использованию комплекса SC_Calculator_MATLAB

Версия 1.2.2, 2026 г. Расчёт токов короткого замыкания по упрощённой схеме замещения (последовательности Фортескью, `E` и сопротивления в о.е.). Версия ПО задаётся в `sc_version.m`.

## 1. Что нужно установить

- **MATLAB** (рекомендуется R2019b и новее — для `uifigure`, `writetable`, импорта Excel).
- Расширение **MATLAB** в Cursor (по желанию) — для подсветки и запуска из редактора.
- Microsoft Excel **не обязателен** для запуска расчёта: MATLAB читает `.xlsx` самостоятельно.

Скопируйте всю папку проекта `SC_Calculator_MATLAB` на диск и в MATLAB выполните:

```matlab
cd('C:\полный\путь\к\SC_Calculator_MATLAB')
```

Дальнейшие команды предполагают, что **текущая папка** — эта папка (или добавьте её в путь: `addpath(pwd)`).

## 1.1. Структура программного комплекса

Комплекс построен по модульному принципу. Главный сценарий `main_calc_sc.m` последовательно вызывает функции импорта, расчёта и вывода результатов. Структурная схема комплекса (для главы 3 диплома, **Рисунок 3.1**) строится командой:

```matlab
draw_structure_scheme
```

Файлы схемы сохраняются в `results/figures/structure_scheme.png` и `.eps`.

**Основные модули (сверху вниз по потоку данных):**

| Модуль | Назначение |
|--------|------------|
| `main_calc_sc.m` | Главный сценарий расчёта |
| `func_import_data.m` | Импорт Excel → Z1, Z2, Z0, E, Uном |
| `func_sym_components.m` | Симметричные составляющие I1, I2, I0 |
| `func_sc_currents.m` | Токи КЗ Ik3, Ik2, Ik1 (кА) |
| `func_impact_current.m` | Ударный ток iуд, kуд |
| `func_network_tau.m` | Постоянная времени τ |
| `func_pack_results_meta.m` | Метаданные для отчёта и экспорта |
| `func_oscillogram.m` | Осциллограмма → `results/figures/` |
| `func_export_results.m` | Таблица результатов |
| `func_report.m` | Текстовый отчёт |
| `sc_calculator_gui.m` | Графический интерфейс (MATLAB) |
| `sc_ensure_results_dirs.m` | Создание каталогов `results/` при первом запуске |

Подробное описание — в `docs/razdel_3_1.md` (текст подраздела 3.1 диплома).

## 1.2. Сценарий работы инженера

Типовой порядок работы пользователя (инженера энергетика):

1. **Подготовка данных.** Заполнить таблицу `network_parameters.xlsx` параметрами элементов сети (R1, X1, R0, X0, Uном; при необходимости R2, X2).
2. **Запуск расчёта.** В MATLAB: `main_calc_sc` или `sc_calculator_gui`. В Octave: `run_sc_octave` или `oct_sc_menu`. Для пакетного режима: `main_calc_sc('имя_файла.xlsx')`.
3. **Контроль хода.** В Command Window отображаются этапы `[1/7]…[7/7]` и сводная таблица токов КЗ, iуд, τ.
4. **Анализ результатов.** Открыть осциллограмму в `results/figures/`, таблицу в `results/results_sc.xlsx` (или `.tsv`), отчёт в `results/docs/report_sc.txt`.
5. **Верификация (по необходимости).** Выполнить `run_all('test')` или `run_sc_tests` — см. `docs/VERIFICATION.md`.

При первом запуске каталоги `results`, `results/figures`, `results/docs` создаются автоматически.

## 2. Файл параметров сети `network_parameters.xlsx`

Таблица на **первом листе** (как обычный `readtable` после `detectImportOptions`).

Обязательные столбцы (имена в первой строке):

| Столбец   | Смысл |
|-----------|--------|
| `Element` | Подпись элемента (текст), для отчёта |
| `R1`      | Активное сопротивление прямой последовательности, Ом |
| `X1`      | Реактивное сопротивление прямой последовательности, Ом |
| `R0`      | Активное сопротивление нулевой последовательности, Ом |
| `X0`      | Реактивное сопротивление нулевой последовательности, Ом |
| `U_nom`   | Номинальное напряжение сети, **кВ** (в первой строке данных; для нескольких строк обычно одно значение) |

**Необязательно** (если оба столбца есть, используются для обратной последовательности):

| Столбец | Смысл |
|---------|--------|
| `R2`    | Активное сопротивление обратной последовательности, Ом |
| `X2`    | Реактивное сопротивление обратной последовательности, Ом |

Программа переводит омические сопротивления в **относительные единицы** по базису **Sбаз = 100 МВА**:  
`Zбаз = Uном² / 100` (Ом), затем суммирует строки:  
`Z1 = sum((R1 + j·X1) / Zбаз)`, `Z0 = sum((R0 + j·X0) / Zбаз)`.  
Если заданы **`R2` и `X2`**, то `Z2 = sum((R2 + j·X2) / Zбаз)`; иначе **`Z2 = Z1`**.

ЭДС в модели задана константой **`E = 1.05` о.е.** (см. `func_import_data.m`).

**Ударный ток:** коэффициент `k_уд` вычисляется по суммарному отношению **R/X** цепи прямой последовательности (омически, после суммирования строк): аппроксимация **κ = 1.02 + 0.98·exp(−3·R/X)** с ограничением **1…1.8** (см. `func_impact_current.m`). Ранее использовалось фиксированное `k_уд = 1.8`.

**Осциллограмма:** постоянная времени **τ ≈ X/(ωR)** по суммарному **Z1** в омах; на графике по умолчанию три фазы и угол коммутации **ψ** (в `main_calc_sc.m` и в GUI).

Пример одной строки (как в учебном задании):

- `Element`: Система  
- `R1, X1, R0, X0`: 0.5, 8.5, 0.8, 6.5  
- `U_nom`: 10  

Сохраните файл в папку проекта под именем `network_parameters.xlsx` или укажите своё имя в GUI.

## 3. Запуск из командной строки MATLAB

### Один запуск без поочерёдного открытия файлов (`run_all`)

После `cd` в папку проекта выполните **одну** команду:

```matlab
run_all              % полный расчёт (эквивалент main_calc_sc)
run_all('calc')      % то же
run_all('test')      % только верификация (verify_sc_suite)
run_all('both')      % сначала расчёт, затем тесты
```

Функция сама делает `cd` в каталог, где лежит `run_all.m`, добавляет проект и папку `tests` в путь. В **GNU Octave** перед расчётом вызывается `sc_octave_init` (пакет `io`, графический toolkit).

**Альтернатива в Octave:** скрипт `run_sc_octave` — то же по смыслу, что `run_all` без тестов (удобен из командной строки ОС).

### Вариант А — основной сценарий (как раньше)

```matlab
main_calc_sc
main_calc_sc('network_parameters.xlsx')
main_calc_sc('C:\data\my_network.xlsx')
```

Ожидается файл **`network_parameters.xlsx`** в текущей папке (если аргумент не указан). Выполняется:

1. импорт Excel;  
2. расчёт симметричных составляющих и токов КЗ;  
3. ударный ток (`k_уд` по R/X);  
4. график осциллограммы (τ по суммарному Z1, опционально три фазы);  
5. вывод в **Command Window**;  
6. экспорт в Excel/TSV и текстовый отчёт (версия, Z в о.е., τ, `k_уд`, имя входного файла).

### Вариант Б — графический интерфейс

```matlab
sc_calculator_gui
```

- В поле пути укажите **`network_parameters.xlsx`** или полный путь к любому совместимому `.xlsx`.  
- Кнопка **«Обзор…»** открывает диалог выбора файла.  
- Поля **частота f**, **интервал T**, **угол ψ** и флажок **«Три фазы на осциллограмме»** задают параметры графика.  
- **«Выполнить расчёт»** запускает тот же расчёт, что и `main_calc_sc`, с записью результатов в папку **`results`** проекта.

## 4. Куда сохраняются результаты

## 6. Типичные проблемы

- **«Не найден файл»** — проверьте `cd` и имя файла; в GUI используйте «Обзор…» или полный путь.  
- **Ошибка при чтении таблицы** — проверьте имена столбцов (латиница, без пробелов в начале/конце) и что данные числовые в `R1`, `X1`, `R0`, `X0`, `U_nom`.  
- **Пустой или странный график** — убедитесь, что `Ik3` не нулевой и что `T` > 0.  
- **GUI не открывается** — обновите MATLAB; для очень старых версий используйте только `main_calc_sc.m` или перенесите интерфейс в **App Designer** вручную (см. ниже).

## 7. Перенос в App Designer (по желанию)

Файл `sc_calculator_gui.m` задаёт те же шаги, что и `main_calc_sc.m`. В App Designer можно:

1. Создать новый **Desktop App** (`Blank App`).  
2. Разместить поля ввода (путь к Excel, `f`, `T`, угол `ψ`, флажок «три фазы»), кнопки «Обзор» и «Расчёт», область вывода текста.  
3. В callback кнопки «Расчёт» вставить код из функции `runCalc` внутри `sc_calculator_gui.m` (вызовы `func_import_data` … `func_report`), подставив `rootDir` как `fileparts(mfilename('fullpath'))` в методе `startupFcn` приложения.

Так вы получите `.mlapp` для диплома с классическим видом «приложения MATLAB».

## 8. Ограничения принятой математической модели

Комплекс реализует **упрощённую расчётную модель** токов короткого замыкания. При интерпретации результатов и включении их в проектную документацию необходимо учитывать следующие ограничения.

### 8.1. Схемные допущения

- Рассматривается **одна точка КЗ**; сопротивления элементов **суммируются** по строкам Excel (эквивалент последовательного суммирования ветвей в о.е.).
- **`Z2`** по умолчанию принимается равным **`Z1`**; при необходимости задаётся столбцами **`R2`, `X2`**.
- Базисная мощность **Sбаз = 100 МВА**; базисное сопротивление **Zбаз = Uном² / 100** (Ом).
- ЭДС системы **`E = 1,05` о.е.** — постоянная; не учитываются тип источника, нагрузка до КЗ, изменение напряжения.

### 8.2. Ударный ток и переходный процесс

- Коэффициент **kуд** определяется по суммарному отношению **R/X** цепи прямой последовательности (аппроксимация по IEC 60909-0), а не по полной модели вращающихся машин.
- Осциллограмма — **иллюстративная** симметричная RL-модель с τ ≈ X/(ωR); **не является** результатом электромагнитного моделирования (ЭМТП, Simulink Power Systems).

### 8.3. Программные ограничения

- GUI (`sc_calculator_gui.m`) доступен только в **MATLAB** (требуется `uifigure`).
- В **GNU Octave** экспорт таблицы выполняется в формате **TSV**, а не XLSX.
- Модель не поддерживает несколько узлов КЗ, COMTRADE, автоматический выбор места КЗ по топологии сети.

При необходимости указанные ограничения могут быть сняты доработкой отдельных модулей под конкретную схему 110/10 кВ объекта исследования.

## 8.1. Самопроверки (`run_sc_tests`)

Из корня проекта в MATLAB или Octave:

```matlab
cd('C:\полный\путь\к\SC_Calculator_MATLAB')
run_sc_tests
```

Проверяются формулы `k_уд`, постоянной τ и согласованность тока `Ik3` с `func_sym_components` / `func_sc_currents`.

Полный набор верификации (модульные + интеграционный тест при наличии Excel): команда **`run_sc_tests`**, см. **`docs/VERIFICATION.md`** и журнал **`results/docs/verification_report.txt`**.

## 9. Запуск в GNU Octave (основной сценарий без MATLAB)

Если MATLAB недоступен или нет лицензии, проект рассчитан на **GNU Octave**.

1. Установите Octave: [https://octave.org/download](https://octave.org/download)  
2. В Octave перейдите в папку проекта (подставьте свой путь):

```octave
cd('c:/Projekt/Maga/SC_Calculator_MATLAB')
```

3. Один раз установите пакет **io** (чтение `.xlsx`):

```octave
pkg install -forge io
```

### 9.1. Быстрый расчёт (как `main_calc_sc`)

Скрипт сам перейдёт в свою папку, добавит путь, загрузит `io`, выберет графический toolkit и вызовет `main_calc_sc`:

```octave
run_sc_octave
```

Внутри используется `sc_octave_init.m` (загрузка `io`, `graphics_toolkit`: qt → fltk → gnuplot).

### 9.2. Интерактивно (путь к Excel, f, T, угол, три фазы)

```octave
oct_sc_menu
```

Появятся запросы в командной строке; результаты пишутся в `results/` относительно папки проекта.

### 9.3. Самопроверки

```octave
run_sc_tests
```

### 9.4. Ограничения в Octave

- **`sc_calculator_gui.m`** в Octave **не запускается** (нет `uifigure`); при вызове будет понятное сообщение об ошибке. Используйте **`run_sc_octave`** или **`oct_sc_menu`**.  
- Экспорт — файл **`results/results_sc.tsv`** (табуляция).  
- Если график не сохранился, проверьте toolkit: `available_graphics_toolkits` и при необходимости `graphics_toolkit('qt')`.
