# Приложение Б. Описание блок-схем и структурных схем программного комплекса

## Б.1 Структурная схема комплекса M-file сценариев (Рисунок 3.1)

**Наименование рисунка:** Рисунок 3.1 — Структурная схема комплекса M-file сценариев.

**Файл построения:** `draw_structure_scheme.m`.

**Форматы экспорта:** `results/figures/structure_scheme.png` (300 dpi), `results/figures/structure_scheme.eps` (вектор).

### Б.1.1 Назначение схемы

Структурная схема отражает состав программного комплекса SC_Calculator, связи между M-file модулями и направление потока данных. Схема не описывает топологию электрической сети, а представляет архитектуру прикладного программного обеспечения для расчёта токов короткого замыкания.

### Б.1.2 Элементы схемы (сверху вниз)

| Блок | Обозначение | Назначение |
|------|-------------|------------|
| 1 | `sc_calculator_gui.m` | Графический интерфейс MATLAB (uifigure) |
| 2 | `run_sc_octave.m` / `oct_sc_menu.m` | Точки входа GNU Octave |
| 3 | `run_all.m` | Унифицированный запуск расчёта и тестов |
| 4 | **`main_calc_sc.m`** | **Главный сценарий — координация всех этапов** |
| 5 | `func_import_data.m` | Импорт Excel → Z1, Z2, Z0, E, Uном |
| 6 | `func_sym_components.m` | Симметричные составляющие I1, I2, I0 |
| 7 | `func_sc_currents.m` | Токи КЗ Ik3, Ik2, Ik1 (кА) |
| 8 | `func_impact_current.m` | Ударный ток iуд, коэффициент kуд |
| 9 | `func_network_tau.m` | Постоянная времени τ |
| 10 | `func_pack_results_meta.m` | Сборка метаданных для отчёта |
| 11 | `func_oscillogram.m` | Осциллограмма → `results/figures/` |
| 12 | `func_export_results.m` | Таблица → `results/` |
| 13 | `func_report.m` | Текстовый отчёт → `results/docs/` |

Стрелки на схеме показывают последовательность вызова функций главным сценарием. Блоки 6–10 выполняются после импорта данных; блоки 11–13 — параллельно на этапе вывода результатов.

### Б.1.3 Входные и выходные данные

- **Вход:** файл `network_parameters.xlsx` (или иной совместимый Excel-файл, указанный аргumentом `main_calc_sc`).
- **Выход:** осциллограмма в `results/figures/`, таблица `results/results_sc.xlsx` (или `.tsv` в Octave), отчёт `results/docs/report_sc.txt`.

### Б.1.4 Порядок получения рисунка для диплома

1. Открыть MATLAB или GNU Octave.
2. Перейти в каталог проекта: `cd('…\SC_Calculator_MATLAB')`.
3. Выполнить: `draw_structure_scheme`.
4. Вставить файл `results/figures/structure_scheme.png` или векторный EPS в текст диплома.
5. Под рисунком разместить подпись: **«Рисунок 3.1 — Структурная схема комплекса M-file сценариев»**.

## Б.3 Блок-схема алгоритма главного сценария

Алгоритм `main_calc_sc.m` может быть представлен блок-схемой со следующими основными блоками:

```
[НАЧАЛО]
    ↓
[Инициализация: пути, каталоги results, Octave io]
    ↓
[Импорт Excel — func_import_data]
    ↓
[Симметричные составляющие — func_sym_components]
    ↓
[Токи КЗ — func_sc_currents]
    ↓
[Ударный ток — func_impact_current]
    ↓
[τ и метаданные — func_network_tau, func_pack_results_meta]
    ↓
[Осциллограмма — func_oscillogram]
    ↓
[Вывод в Command Window]
    ↓
[Экспорт — func_export_results, func_report]
    ↓
[КОНЕЦ]
```

Блок-схема подтверждает линейную структуру главного сценария: каждый блок имеет единственный вход и выход, что упрощает верификацию и сопровождение комплекса.

4. Все подрисуночные надписи оформлять по ГОСТ Р 7.0.11-2011 и СТО 005-2015 ИРНИТУ: «Рисунок X.Y — …» без точки в конце.
