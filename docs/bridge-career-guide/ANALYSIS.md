## Уязвимости и риски

### Критично / высокий риск (до продакшена с реальными пользователями)

1. **Сессия только в `localStorage`** — любой скрипт на странице или XSS читает профиль/результаты; нет серверных сессий/HttpOnly cookie.
2. **Демо-OTP на экране** — если Worker/Resend не настроены, код виден в UI; на публичном домене это обход «проверки почты».
3. **`innerHTML` с данными** — тексты вузов/результатов вставляются в HTML; сейчас данные свои, но при подтягивании внешнего контента возможен XSS. Нужен escape / `textContent`.
4. **4-значный OTP** — всего 10 000 вариантов; без жёсткого rate-limit брутфорс реален. В Worker есть лимит IP, но KV id должен быть реальным.
5. **Нет серверного хранения согласий** — юридически слабее, чем лог согласия на бэкенде.

### Средний риск

6. CORS `*` на API — ок для публичного OTP, но при появлении cookie-сессий сузить Origin.
7. Парсер tuition — ложные цифры возможны; смягчено проверкой «рядом с tuition» + полосой vs каталог.
8. Курсы FX захардкожены — устаревают.
9. Пользователь «существует» только в браузере — с другого устройства login = «not_found» (нет облачного аккаунта).

### Низкий / продукт

10. Hash-роутинг `#/uni/...` — ок для MVP; для SEO лучше History API + prerender.
11. Нет CSP / security headers в Worker.

| Элемент | Почему |
|---------|--------|
| **`data.js`** | Не подключён; дублирует старые 8 вузов и короткий тест |

| **Демо-показ OTP в проде** | Только для локалки |
| **Дублирующие CTA** «печатать PDF» без нормальной вёрстки** | Можно оставить позже, не в первом экране |
| **Старый modal-only UX вузов** | Уже заменён страницами `#/uni/:id` |

## Что добавить (приоритет)

### P0 — чтобы сайт был «настоящим»

1. Настроить Resend + KV по `EMAIL-OTP-SETUP.md`
2. Серверные аккаунты (D1/KV): email, согласия, результат теста
3. Escape HTML во всех рендерах; CSP headers в Worker
4. 6-значный OTP или cooldown после 5 ошибок

### P1 — продукт для абитуриента

5. Фильтры вузов: город, цена, язык, кластер, наличие гранта
6. Сравнение 2–3 вузов
7. Актуальные дедлайны CSC / подачи (календарь)
8. Автообновление FX (API курса) раз в сутки
9. Парсер документов с PDF admission guide (сложнее tuition)
10. Экспорт результата теста в PDF на языке UI

### P2 — рост

11. Личный кабинет «мои заявки / чек-лист в облаке»
12. Уведомления на почту о дедлайнах
13. Админ-панель правки вузов без правки JS
14. Поиск по каталогу + карта Китая
15. Eval/качество матчинга теста (ручные эталоны)
