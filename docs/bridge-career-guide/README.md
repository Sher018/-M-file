# BRIDGE — персональный гид поступления в Китай

## Что умеет сейчас

- Регистрация по email + согласия (рамка 152-ФЗ РФ / персональные данные РТ)
- Тест направления → персональный список вузов Китая
- Кликабельные вузы: документы, экзамены/CSCA, бюджетные таблицы
- Фильтры: Все / Мечта / Реализм / Бюджет / Мои
- Чек-лист прогресса (localStorage)

> MVP: аккаунты хранятся в браузере. Для продакшена нужен сервер, HTTPS, политика конфиденциальности и полноценная аутентификация.

## Локально

```bash
cd docs/bridge-career-guide
python3 -m http.server 8080
```

Открой `http://localhost:8080`.

## Деплой Cloudflare (временный / claim)

```bash
cd docs/bridge-career-guide
npx wrangler@4.102.0 deploy --temporary
```
