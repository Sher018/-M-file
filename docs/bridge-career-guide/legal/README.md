# BRIDGE — правовые страницы (legal)

Статические HTML-документы для регистрации и прозрачности обработки данных в MVP карьерного гида **BRIDGE** (`../index.html`). Подключают общий стиль `../styles.css`.

| Файл | Назначение |
|------|------------|
| [privacy-consent.html](./privacy-consent.html) | Полное согласие на обработку персональных данных (152-ФЗ РФ, принципы Таджикистана): перечень данных, цели, localStorage MVP, права субъекта, трёхъязычное ключевое согласие (RU / EN / TG). |
| [age-consent.html](./age-consent.html) | Возраст и участие несовершеннолетних: минимум 14 лет, осведомлённость родителей/опекуна до 18 лет, трёхъязычное подтверждение. |
| [terms.html](./terms.html) | Информационные условия: советы не гарантируют поступление; обязанность сверять требования на сайтах вузов; ограничение ответственности. |

Ссылки с главной страницы можно вести на эти файлы из чекбоксов согласия при регистрации.
