# PROJECT_IDEA — BRIDGE

> Гид по поступлению в вузы Китая для абитуриентов из Таджикистана и России.
> Документ написан для AI-агентов (Spec-First, слой 1). Из него генерируется SPECIFICATION.md.
> Статус: **v1.0 — утверждён владельцем продукта**, готов к генерации SPECIFICATION.md.

---

## 1. Проблема

Абитуриент из Душанбе или Казани, который хочет учиться в Китае на английском, сегодня:

- открывает 10–30 сайтов вузов (половина только на китайском, часть — устаревшие PDF 2022–2023 года);
- не понимает разницу между грантами: CSC (государственный), провинциальный (Jiangsu Jasmine, Shanghai Government), университетский (Presidential), Confucius Institute;
- тратит **2–4 недели** на сбор списка документов и всё равно упускает что-то (например, нотариальный перевод справки о несудимости или форму Physical Examination);
- пропускает дедлайны: CSC — обычно январь–апрель, вузовские — до 30 июня, а узнаёт об этом в мае;
- платит агентам **$500–2500** за ту же информацию, которая есть в открытом доступе, но разрознена;
- не знает, какая специальность ему подходит, и выбирает «что скажут родители».

Текущие обходные решения: Telegram-чаты, агенты, CUCAS / China Admissions (платные посредники, англоязычные, без RU/TG, без персонального трекинга).

## 2. Решение

BRIDGE — веб-приложение (PWA), работающее на телефоне и ПК. Пошаговый сценарий:

1. **Гость** открывает сайт → видит лендинг: что это, для кого, как работает, 3 скриншота, кнопка «Начать».
2. **Регистрация** — email + 4-значный код (уже работает через Resend). Принимает согласия (персональные данные, возраст, условия).
3. **Профориентация** (опционально, 10–15 минут) — тест Big Five + DISC + ценности + мотивация → 2–3 кластера профессий → рекомендуемые направления и вузы.
4. **Каталог вузов** — карточки с фильтрами: город, тип (C9 / 985 / 211 / провинциальный / Sino-UK), цена в год (CNY / USD), язык программ, наличие грантов, кластер.
5. **Страница вуза** — рейтинг, мини-карта Китая с точкой города, квота для иностранцев, стоимость (обучение + общежитие + страховка), список грантов (кликабельные → требования и покрытие), список документов (кликабельные → что это и как получить), официальные ссылки, дата последнего обновления данных.
6. Пользователь нажимает **«Добавить в мой путь»** на вузе и отмечает **1–3 гранта** внутри него.
7. **«Мой путь в Китай»** — личный план: выбранные вузы и гранты, объединённый список документов (без дубликатов), таймлайн дедлайнов (CSC, вузовские, подача на визу X1), чекбоксы прогресса, процент готовности. MVP — в браузере (localStorage); с v1 синхронизируется между телефоном и ПК через аккаунт.
8. **Напоминания** (v2) — письмо за 30 / 14 / 3 дня до дедлайна.

## 3. Почему сейчас

- Китай с 2023 года активно возвращает иностранных студентов после ковида; квоты и гранты расширяются, особенно для стран «Пояса и пути» (Таджикистан входит).
- Количество EN-программ бакалавриата выросло — поступать можно без HSK.
- У РФ ограничен доступ к западным вузам → Китай стал основным направлением.
- Cloudflare Workers + D1 позволяют держать весь сервис почти бесплатно (до десятков тысяч пользователей).
- AI-парсинг (LLM-экстракция из PDF admission guide) стал дешёвым — можно поддерживать актуальность данных полуавтоматически.

| Сегмент | Кто | Задача | Сейчас пользуется |
|---------|-----|--------|-------------------|

**Стек и обоснование**

| Слой | Выбор | Почему |
|------|-------|--------|
| Frontend | Vanilla JS + CSS (без фреймворка) | Уже написано, 0 зависимостей, быстро грузится на слабых телефонах в ТЖ |
| Хостинг | Cloudflare Workers + Static Assets | Уже задеплоено на `bridge-tj.lol`, бесплатный тариф |
| БД | Cloudflare D1 (SQLite) | Реляционные данные «пользователь → вузы → гранты → чекбоксы», бесплатно |
| Кэш/сессии | Cloudflare KV | OTP-коды, rate-limit, сессии |
| Email | Resend | Уже подключён; домен `bridge-tj.lol` верифицируем для отправки на любые адреса |
| Карта | SVG-контур Китая + координаты городов (без внешних тайлов) | Работает офлайн, без ключей, 1 файл |
| Данные | JSON в репозитории → seed в D1 | Версионируемость, ревью изменений через git |

**Дизайн-система** — референс **apple.com**:

- Шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Inter", "Segoe UI", sans-serif`. На устройствах Apple это SF Pro; на остальных — Inter (Google Fonts). Сам SF Pro лицензионно нельзя раздавать с сайта.
- Много воздуха, крупные заголовки (56–80px на desktop), короткие фразы, нейтральный фон + зелёная палитра бренда.
- **Палитра бренда** (утверждена владельцем):

  | Токен | Название | HEX | Применение |
  |-------|----------|-----|-----------|
  | `--brand-900` | Dark Evergreen | `#013220` | Тёмные секции, футер, заголовки на светлом, текст кнопок на мятном |
  | `--brand-600` | Royal Amethyst (deep green) | `#0B6E4F` | Основной акцент: кнопки, ссылки, активные фильтры, точка на карте |
  | `--brand-400` | Emerald Green | `#50C878` | Успех/прогресс, выполненные чекбоксы, бейдж «есть грант», hover |
  | `--brand-100` | Mint Whisper | `#D1F2EB` | Фон карточек-подсказок, выделенные блоки, фон тегов |
  | `--neutral-0 / -900` | — | `#FFFFFF` / `#1D1D1F` | Фон страницы / основной текст (как у apple.com) |

  Контраст: текст `#013220` на `#D1F2EB` — AA/AAA; белый текст на `#0B6E4F` — AA; белый на `#50C878` — **не проходит AA**, поэтому Emerald используется только для заливок/иконок, не для текста на нём.
- Тёмная тема (v1): фон `#013220` → `#0A1F17`, акцент `#50C878`, карточки `#0B6E4F` с прозрачностью.
- Карточки с радиусом 18–24px, мягкие тени, без градиентного шума.
- Секции во весь экран с центровкой; плавные появления при скролле.
- Навигация — тонкая полупрозрачная панель с blur сверху.

**Модули (вход → выход)**

| Модуль | Вход | Выход |
|--------|------|-------|
| Auth | email, код | сессия (cookie), user_id |
| Test | ответы на 60–80 вопросов | профиль черт, 2–3 кластера, рекомендации |
| Catalog | фильтры | список вузов; страница вуза с грантами/документами |
| MyPath | выбранные uni_id + grant_id | объединённые документы, дедлайны, прогресс % |
| Reminders (v2) | дедлайны из MyPath | письма за 30/14/3 дня |
| Data pipeline | официальные URL / PDF | catalog.json с полем `updated_at` и `source_url` |

## 6. Монетизация

Сайт создан как помощь; монетизация — **не раньше v2** и не должна блокировать базовый сценарий.
Решение по модели **ещё не принято** — ниже варианты для выбора владельцем продукта. Они совместимы друг с другом (можно взять 2–3).

| # | Модель | Как работает | Доход (оценка) | Плюсы | Минусы / риски |
|---|--------|-------------|----------------|-------|----------------|
| A | **Freemium «Plus»** | Ядро бесплатно; Plus ~$5–9/год: до 10 вузов в пути, PDF-экспорт, email-напоминания, сравнение | При 5 000 польз. и 5 % конверсии ≈ $1 500–2 000/год | Просто, честно, не ломает доверие | Низкий чек; аудитория ТЖ чувствительна к цене; нужен приём оплаты (Stripe недоступен в ТЖ/РФ — см. ниже) |
| B | **Разовая «Проверка пакета документов»** | Пользователь загружает чек-лист → живой человек (вы/брат) проверяет комплектность за $15–30 | 20 проверок/мес ≈ $300–600/мес | Высокая ценность, не требует разработки, можно начать с MVP | Ручной труд, не масштабируется, ответственность за ошибки |
| C | **B2B для школ и центров** | Кабинет куратора на 10–50 учеников, $100–300/год на организацию | 10 школ ≈ $1 000–3 000/год | Один клиент = много пользователей; платят организации, а не студенты | Долгие продажи, нужен v3-функционал |
| D | **Партнёрские сервисы (реклама)** | Проверенные бюро переводов, нотариусы, клиники медсправок, страховка — помечено «реклама», оплата за размещение или лид | $50–200/мес на партнёра | Пассивный доход, полезно пользователю | Риск «агентского» имиджа; нужна жёсткая модерация, только нужные сервисы |
| E | **Донаты / «Поддержать проект»** | Кнопка пожертвования (криптокошелёк / местные платёжки) | Непредсказуемо, $0–200/мес | Нулевые обязательства, не портит продукт | Не покрывает развитие |
| F | **Грант / спонсорство** | Образовательные фонды, посольство КНР, Confucius Institute, IT-парки ТЖ — финансирование как социального проекта | Разово $2 000–20 000 | Крупная сумма, статус | Отчётность, зависимость от спонсора |
| G | **Сопровождение с партнёром-агентом (white-label)** | Пользователю «хочу, чтобы подали за меня» → передача лицензированному агенту за комиссию | $50–150 за студента | Самый высокий чек | **Противоречит принципу независимости**; возможен только если агент прозрачен и помечен как внешняя услуга |

**Ограничение по платежам**: Stripe/PayPal не работают для получателей в ТЖ и РФ. Реалистичные каналы: криптовалюта (USDT), местные платёжки (Alif, DC в ТЖ; ЮMoney/СБП в РФ), Paddle/LemonSqueezy при регистрации юрлица вне ТЖ/РФ.

**Решение владельца продукта**:

| Фаза | Модель | Реализация |
|------|--------|-----------|
| MVP / v1 | **E — Донаты** | Кнопка «Поддержать проект» → ЮMoney (кошелёк владельца, есть; форма/ссылка `yoomoney.ru/to/<id>`); для ТЖ и других стран — USDT-адрес. Без бэкенда: статическая ссылка + QR. |
| v1 | **D — Партнёрские сервисы** | Раздел «Проверенные сервисы» (переводы, нотариус, медсправки, страховка). Каждый помечен «реклама/партнёр», добавляется вручную владельцем через `data/partners.json`. Оплата от партнёра — вне сайта. |
| v2+ | **G — Лицензированные агенты** | Только когда владелец найдёт надёжных агентов с лицензией. Отдельная кнопка «Хочу, чтобы подали за меня» → форма заявки → передача агенту. Жёстко помечено как внешняя услуга; агент показывает лицензию, цену и условия до контакта. Сайт не принимает оплату за эту услугу. |

Отложено (не исключено): A — Plus, B — проверка документов, C — школы, F — гранты.

Принцип неизменен: **никогда не брать деньги за информацию о грантах и документах** — это ядро доверия.

## 7. Конкуренты

|-----------|-----------|-----------------|
| CUCAS, China Admissions, SICAS | Каталог + платная подача заявки ($100–300) | Нет RU/TG, нет личного плана, продают услугу посредника |
| campuschina.org (официальный CSC) | Список вузов и гранта CSC | Только английский/китайский, неудобный поиск, нет документов «как получить» |

| Агенты в Душанбе / Москве | Делают всё за абитуриента | $500–2500, непрозрачно, конфликт интересов (ведут в «свои» вузы) |
| YouTube-блогеры | Опыт одного человека | Не актуализируется, не персонально |

**Отличие BRIDGE**: бесплатное ядро, RU/TG, тест профориентации, персональный план с дедлайнами, данные с датой обновления и ссылкой на источник.

| Чат-бот / AI-помощник | 🔁 v3, только поверх наших данных | v3 |

#### Что у конкурентов есть, но делать **не будем**

| Функция | Почему |
|---------|--------|
| Приём оплаты за подачу заявки, прохождение статуса за студента | Становимся агентом → лицензия, ответственность, конфликт интересов |
| Хостинг сканов паспортов и аттестатов | Персональные данные несовершеннолетних; достаточно чекбоксов |
| Партнёрская сеть агентов и «агентские вознаграждения» | Противоречит независимости сайта |
| Программы на китайском языке как основной фокус | Наша аудитория — EN-треки; китайские программы показываем, но не приоритизируем |
| Хостинг видео, форум | Дорого поддерживать, не критично для сценария |

#### Что требуется, чтобы паритет был реальным

1. **Data-pipeline как главный модуль**, а не побочный: парсер цен → парсер дедлайнов → LLM-экстракция программ и грантов из admission guide → ревью → релиз. Без этого 300 вузов не поддержать.
2. **Структура данных уровня CUCAS** с первого дня: `University → Program → Scholarship → Deadline → Document → City` (см. раздел 10). Переделывать потом дороже.
3. **Поле `updated_at` + `source_url` на каждом факте** — то, чего нет у конкурентов и что делает нас надёжнее.
4. **Контент-разделы (виза, HSK, жизнь)** — **только из официальных источников, ничего не придумывается**: посольства КНР в ТЖ/РФ, campuschina.org / csc.edu.cn, chinesetest.cn (HSK), сайты вузов, визовые центры. Каждый абзац гида несёт `source_url` и `checked_at`; если источник не найден — раздел помечается «нет данных», а не заполняется домыслом. Черновики собирает AI → ревью владельца → перевод на TG/EN.

## 9. Риски

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Устаревшие цены/дедлайны → потеря доверия | Высокая | Поле `updated_at` + `source_url` на каждом факте; парсер раз в неделю; кнопка «Сообщить об ошибке» |
| Нельзя охватить «все вузы Китая» | Высокая | Честно: «150 вузов с EN-программами», не «все»; приоритет по спросу РФ/ТЖ |
| Resend free tier (100 писем/день) | Средняя | Верификация домена; при росте — платный тариф $20/мес |
| Пользователь путает сайт с агентом и ждёт «подачи за него» | Средняя | Чёткий дисклеймер на лендинге и в «Моём пути в Китай»: «мы гид, подаёшь ты сам» |
| Персональные данные несовершеннолетних | Средняя | Минимум данных (email, язык), согласие, удаление аккаунта по кнопке |
| Брутфорс 4-значного OTP | Средняя | Rate-limit по IP+email в KV, lockout после 5 попыток |
| Один разработчик (bus factor) | Высокая | Spec-First: вся логика в документах, код генерируется заново при необходимости |
| Юридическая ответственность за советы по визам | Низкая | Только ссылки на официальные источники, формулировка «обычно требуется» |

## Открытые вопросы к владельцу продукта

### Решено
- Каталог: **300+ вузов** (поэтапно 50 → 150 → 300+).
- Степени: **языковые курсы + бакалавр + магистр** (PhD показываем без приоритета).
