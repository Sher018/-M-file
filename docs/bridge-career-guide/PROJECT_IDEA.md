# PROJECT_IDEA — BRIDGE

> Гид по поступлению в вузы Китая для абитуриентов из Таджикистана и России.
> Документ написан для AI-агентов (Spec-First, слой 1). Из него генерируется SPECIFICATION.md.
> Статус: **черновик v0.1** — ждёт правок владельца продукта.

---

## 1. Проблема

Абитуриент из Душанбе или Казани, который хочет учиться в Китае на английском, сегодня:

- открывает 10–30 сайтов вузов (половина только на китайском, часть — устаревшие PDF 2022–2023 года);
- не понимает разницу между грантами: CSC (государственный), провинциальный (Jiangsu Jasmine, Shanghai Government), университетский (Presidential), Confucius Institute;
- тратит **2–4 недели** на сбор списка документов и всё равно упускает что-то (например, нотариальный перевод справки о несудимости или форму Physical Examination);
- пропускает дедлайны: CSC — обычно январь–апрель, вузовские — до 30 июня, а узнаёт об этом в мае;
- платит агентам **$500–2500** за ту же информацию, которая есть в открытом доступе, но разрознена;
- не знает, какая специальность ему подходит, и выбирает «что скажут родители».

Текущие обходные решения: Telegram-чаты, агенты, CUCAS / China Admissions (платные посредники, англоязычные, без RU/TG, без персонального трекинга).

## 2. Решение

BRIDGE — веб-приложение (PWA), работающее на телефоне и ПК. Пошаговый сценарий:

1. **Гость** открывает сайт → видит лендинг: что это, для кого, как работает, 3 скриншота, кнопка «Начать».
2. **Регистрация** — email + 4-значный код (уже работает через Resend). Принимает согласия (персональные данные, возраст, условия).
3. **Профориентация** (опционально, 10–15 минут) — тест Big Five + DISC + ценности + мотивация → 2–3 кластера профессий → рекомендуемые направления и вузы.
4. **Каталог вузов** — карточки с фильтрами: город, тип (C9 / 985 / 211 / провинциальный / Sino-UK), цена в год (CNY/USD/TJS), язык программ, наличие грантов, кластер.
5. **Страница вуза** — рейтинг, мини-карта Китая с точкой города, квота для иностранцев, стоимость (обучение + общежитие + страховка), список грантов (кликабельные → требования и покрытие), список документов (кликабельные → что это и как получить), официальные ссылки, дата последнего обновления данных.
6. Пользователь нажимает **«Добавить в мой путь»** на вузе и отмечает **1–3 гранта** внутри него.
7. **«Мой путь»** — личный план: выбранные вузы и гранты, объединённый список документов (без дубликатов), таймлайн дедлайнов (CSC, вузовские, подача на визу X1), чекбоксы прогресса, процент готовности. Синхронизируется между телефоном и ПК через аккаунт.
8. **Напоминания** (v2) — письмо за 30 / 14 / 3 дня до дедлайна.

## 3. Почему сейчас

- Китай с 2023 года активно возвращает иностранных студентов после ковида; квоты и гранты расширяются, особенно для стран «Пояса и пути» (Таджикистан входит).
- Количество EN-программ бакалавриата выросло — поступать можно без HSK.
- У РФ ограничен доступ к западным вузам → Китай стал основным направлением.
- Cloudflare Workers + D1 позволяют держать весь сервис почти бесплатно (до десятков тысяч пользователей).
- AI-парсинг (LLM-экстракция из PDF admission guide) стал дешёвым — можно поддерживать актуальность данных полуавтоматически.

## 4. Целевая аудитория

| Сегмент | Кто | Задача | Сейчас пользуется |
|---------|-----|--------|-------------------|
| **Основной: абитуриент 16–20 лет (ТЖ, РФ)** | Выпускник школы / 1–2 курс, английский B1–B2 | Выбрать вуз и грант, собрать документы, не пропустить дедлайн | Telegram-чаты, агенты, YouTube |
| **Вторичный: родители** | Платят, принимают решение | Понять цену, безопасность, что реально получить грант | Знакомые, агенты |
| **Вторичный: магистранты 22–28** | Бакалавр на руках | Магистратура EN, CSC тип A/B | CSC-сайт, китайские форумы |
| **Третичный: школы и образовательные центры** | Репетиторы, лицеи в Душанбе/Худжанде | Вести 10–50 учеников | Excel |

Языки интерфейса: **русский (основной), таджикский, английский**.

```

   │ catalog │     │ sessions│       └────────────┘
   └─────────┘     └─────────┘
```

**Стек и обоснование**

| Слой | Выбор | Почему |
|------|-------|--------|
| Frontend | Vanilla JS + CSS (без фреймворка) | Уже написано, 0 зависимостей, быстро грузится на слабых телефонах в ТЖ |
| Хостинг | Cloudflare Workers + Static Assets | Уже задеплоено на `bridge-tj.lol`, бесплатный тариф |
| БД | Cloudflare D1 (SQLite) | Реляционные данные «пользователь → вузы → гранты → чекбоксы», бесплатно |
| Кэш/сессии | Cloudflare KV | OTP-коды, rate-limit, сессии |
| Email | Resend | Уже подключён; домен `bridge-tj.lol` верифицируем для отправки на любые адреса |
| Карта | SVG-контур Китая + координаты городов (без внешних тайлов) | Работает офлайн, без ключей, 1 файл |
| Данные | JSON в репозитории → seed в D1 | Версионируемость, ревью изменений через git |

**Дизайн-система** — референс **apple.com**:

- Шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Inter", "Segoe UI", sans-serif`. На устройствах Apple это SF Pro; на остальных — Inter (Google Fonts). Сам SF Pro лицензионно нельзя раздавать с сайта.
- Много воздуха, крупные заголовки (56–80px на desktop), короткие фразы, чёрный/белый + один акцентный цвет.
- Карточки с радиусом 18–24px, мягкие тени, без градиентного шума.
- Секции во весь экран с центровкой; плавные появления при скролле.
- Навигация — тонкая полупрозрачная панель с blur сверху.

**Модули (вход → выход)**

| Модуль | Вход | Выход |
|--------|------|-------|
| Auth | email, код | сессия (cookie), user_id |
| Test | ответы на 60–80 вопросов | профиль черт, 2–3 кластера, рекомендации |
| Catalog | фильтры | список вузов; страница вуза с грантами/документами |
| MyPath | выбранные uni_id + grant_id | объединённые документы, дедлайны, прогресс % |
| Reminders (v2) | дедлайны из MyPath | письма за 30/14/3 дня |
| Data pipeline | официальные URL / PDF | catalog.json с полем `updated_at` и `source_url` |

## 6. Монетизация

Сайт создан как помощь; монетизация — **не раньше v2** и не должна блокировать базовый сценарий.

| План | Цена | Что входит |
|------|------|-----------|
| **Free** | 0 | Весь каталог, тест, «Мой путь» до 3 вузов, документы, дедлайны |
| **Plus** (v2) | ~$5–9 / год или разовая | До 10 вузов, PDF-экспорт плана, email-напоминания, сравнение вузов |
| **Для школ** (v3) | по договорённости | Кабинет куратора на 10–50 учеников |
| Партнёрские | — | Проверенные сервисы перевода/нотариата, медсправки (только с пометкой «реклама») |

Принцип: **никогда не брать деньги за информацию о грантах и документах** — это ядро доверия.

## 7. Конкуренты

| Конкурент | Что делает | Чего не хватает |
|-----------|-----------|-----------------|
| CUCAS, China Admissions, SICAS | Каталог + платная подача заявки ($100–300) | Нет RU/TG, нет личного плана, продают услугу посредника |
| campuschina.org (официальный CSC) | Список вузов и гранта CSC | Только английский/китайский, неудобный поиск, нет документов «как получить» |
| Telegram-чаты «Учёба в Китае» | Живые ответы | Хаос, нет структуры, информация теряется |
| Агенты в Душанбе / Москве | Делают всё за абитуриента | $500–2500, непрозрачно, конфликт интересов (ведут в «свои» вузы) |
| YouTube-блогеры | Опыт одного человека | Не актуализируется, не персонально |

**Отличие BRIDGE**: бесплатное ядро, RU/TG, тест профориентации, персональный план с дедлайнами, данные с датой обновления и ссылкой на источник.

## 8. План запуска

### MVP (то, что уже есть + минимальная доработка) — «v0.9»

## 9. Риски

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Устаревшие цены/дедлайны → потеря доверия | Высокая | Поле `updated_at` + `source_url` на каждом факте; парсер раз в неделю; кнопка «Сообщить об ошибке» |
| Нельзя охватить «все вузы Китая» | Высокая | Честно: «150 вузов с EN-программами», не «все»; приоритет по спросу РФ/ТЖ |
| Resend free tier (100 писем/день) | Средняя | Верификация домена; при росте — платный тариф $20/мес |
| Пользователь путает сайт с агентом и ждёт «подачи за него» | Средняя | Чёткий дисклеймер на лендинге и в «Моём пути»: «мы гид, подаёшь ты сам» |
| Персональные данные несовершеннолетних | Средняя | Минимум данных (email, язык), согласие, удаление аккаунта по кнопке |
| Брутфорс 4-значного OTP | Средняя | Rate-limit по IP+email в KV, lockout после 5 попыток |
| Один разработчик (bus factor) | Высокая | Spec-First: вся логика в документах, код генерируется заново при необходимости |
| Юридическая ответственность за советы по визам | Низкая | Только ссылки на официальные источники, формулировка «обычно требуется» |

### Ключевые таблицы D1 (v1)

```sql
users         (id uuid PK, email text UNIQUE, lang text, created_at timestamptz, deleted_at timestamptz)
consents      (user_id FK, kind text, version text, accepted_at timestamptz)
test_results  (id, user_id FK, scores jsonb, clusters jsonb, created_at)
paths         (id, user_id FK, uni_id text, created_at)
path_grants   (path_id FK, grant_id text)
path_tasks    (path_id FK, task_key text, done_at timestamptz)
```

Каталог (universities, scholarships, documents, deadlines) в MVP/v1 — **JSON в репозитории**, раздаётся как статика; в D1 только пользовательские данные.

### Ключевые сущности каталога

```
University  { id, name{ru,tg,en}, city_id, tier, rank_qs, quota_intl,

Scholarship { id, name{..}, type: csc|provincial|university|confucius,

              needs_translation, needs_notary, validity_months }

              uni_id?, year }

```

### Мини-карта
SVG-контур Китая (~30 KB), проекция равнопромежуточная; точка города — `<circle>` по `lat/lng → x/y`. Без внешних сервисов и API-ключей.

### AI-пайплайн (v2)
PDF admission guide → текст → LLM-экстракция в схему `Scholarship`/`Deadline` → diff с текущим JSON → PR на ревью человеку → merge → деплой. Автоматически в прод **ничего** не попадает.
