# SC_Calculator_MATLAB

Комплекс M-file сценариев для расчёта токов короткого замыкания (метод симметричных составляющих Фортескью).

**Тема ВКР:** «Разработка M-file сценариев для реализации прикладных задач в электротехнике и энергетике»  
**Автор:** Юнусов Шероз, ИРНИТУ, 2026 г.  
**Версия:** 1.2.2

## Возможности

- Импорт параметров сети из Excel (`func_import_data.m`)
- Расчёт токов трёхфазного, двухфазного и однофазного КЗ
- Ударный ток по отношению R/X (IEC 60909-0)
- Осциллограмма переходного процесса (PNG 300 dpi)
- Экспорт результатов в Excel/TSV и текстовый отчёт
- GUI для MATLAB (`sc_calculator_gui.m`)
- Поддержка GNU Octave (`run_sc_octave.m`, `oct_sc_menu.m`)

## Быстрый старт

```matlab
cd('путь/к/SC_Calculator_MATLAB')
main_calc_sc                          % расчёт с network_parameters.xlsx
main_calc_sc('network_parameters.xlsx') % явное имя файла
draw_structure_scheme                   % рис. 3.1 для диплома
run_all('both')                         % расчёт + тесты
```

В Octave:

```octave
run_sc_octave
```
